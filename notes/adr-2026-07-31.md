# ADR 2026-07-31

Follow-up on [adr-2026-07-24.md].

In a federated learning context, as a user of the library, I want to easily distribute data to the workers, either identically or non-identically distributed.

The package `primitives.data_partitioners` contains the primitives to facilitate the partitioning of datasets. It defines
- the interface `DataPartitioner`
    - single method `partition`
    - returns `Sequence[DataLoader]`
- implementations
    - `IidPartitioner`
    - `PerLabelsPartitioner`
    - `DirichletPartitioner`
    - `GammaPartitioner`

The simulation classes (under `simulations`) should be refactored to accept `Sequence[DataLoader]`.

Example.
```python
def my_experiment(dp: DataPartitioner, dp_kwargs, ...):
    # ...
    loaders = dp.partition(dp_kwargs)
    my_simulation = MySimulation(loaders=loaders, ...)
    # ...
```
