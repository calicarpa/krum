# ADR 2026-06-19

This note complements the [previous one](adr-2026-06-12.md).

Class structure
- **Metric**
- **Orchestrator**
  - Absorbs the responsibilities of the metric manager (which is removed)
  - Removes the context manager, replacing it with a simple global variable holding the current context
    - A context is a tuple of parameter values
    - It is temporary: set at the start of each run, with no stack
- **Storage: NumPy array or Pandas DataFrame**
  - Watch for column name conflicts (e.g. `step`, `value` vs. user-defined columns)

Miscellaneous
- No context stack needed
- Parameter value tuples are unique within the DataFrame
- The orchestrator owns and manages metric data
- No persistence
- Fail-fast: if any run fails, fail everything
- Near-term plan:
  - Multi-process, one process per run
  - No multithreading
  - The orchestrator handles PRNG initialization ("seed cooking")
