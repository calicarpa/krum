A Little Is Enough
==================

ALIE-style attack using exact honest gradient statistics.

This implementation computes the coordinate-wise mean and standard deviation
from the honest gradients passed to the attack. This corresponds to a
statistics-oracle variant of ALIE rather than the original paper's more
restricted information setting. Use :class:`attacks.Direction` to choose the
perturbation direction.
