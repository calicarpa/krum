# ADR 2026-05-22

The library is organized in (for now) two packages
- primitives
- simulations
- orchestration

# Package `primitives`

The `primitives` package contains
- Aggregator interface and implementations
- Attack interface and implementations
- Model class (encapsulating a nn.Module)
    - parameters: Tensor
    - gradients: Tensor

These classes (especially the class Model) are designed so that
- the end-user should never care about flattening tensors
- the end-user will have to care about tensor copy, swap and sharing (parameters, or gradients)

# Package `simulations`

The `simulations` package contains reusable simulations of well-known papers.

Single parameter server
- [Machine learning with adversaries: byzantine tolerant gradient descent](https://papers.nips.cc/paper_files/paper/2017/file/f4b9ec30ad9f68f89b29639786cb62ef-Paper.pdf)
- [The hidden vulnerability](https://infoscience.epfl.ch/server/api/core/bitstreams/1efca80d-0b20-47ef-807f-c3cb744a8caa/content)


Decentralized
- Monna [Robust collaborative learning with linear gradient overhead](https://arxiv.org/pdf/2209.10931)

# Package `orchestration`

The `orchestration` package contains the logic to manage 1000s of simulation runs
and process their results. Will be designed in a later discussion.
